# Awesome HarmonyOS Code

# About
A list of awesome open source HarmonyOS projects.

# Content

## AI
- [Kelivo](https://github.com/Chevey339/kelivo) - LLM 聊天客户端

## Browser
- [冲浪猫](https://github.com/awaLiny2333/LinysBrowser_NEXT) - A basic browser on HarmonyOS NEXT

## Security
- [TOTPTOKEN](https://github.com/SolidFaker/ohtotptoken) - TOTP & Forti Token for HarmonyOS Next
- [KDAuth](https://github.com/kdada/Authenticator) - 2FA Authenticator for HarmonyOS Next
- ~~[Aigis](https://github.com/iamhyc/Aigis)~~ - TOTP 2FA Authenticator for HarmonyOS NEXT (已停止开发)
- [KeePassHO](https://github.com/aimilin6688/KeePassHO) - 密码管理

## Image
- [Pixiv](https://github.com/bgli100/pixez-flutter-ohos) - 支持免代理直连及查看动图的第三方Pixiv flutter客户端
- [Immich](https://github.com/dgh1818/immich_ohos) - 连接 Immich 私人照片和视频备份服务器的鸿蒙客户端

## Music
- [Melotopia](https://github.com/Chenlvin/Melotopia-HMOS) - 原生音乐播放器
- [Harmonic](https://github.com/shanyan-wcx/Harmonic) - Navidrome的鸿蒙原生客户端

## Video
- [Kazumi](https://github.com/ErBWs/Kazumi) - 基于自定义规则的番剧采集APP
- [FinVideo](https://github.com/OHPG/FinVideo) - Jellyfin视频播放器
- [Etohos](https://github.com/niuhuan/etohos) - 用来接入 EasyTier 网络
- [Jellyfin_HarmonyOS](https://github.com/chashaochang/JellyFin_HarmonyOS) - 非官方Jellyfin实现
- [SweetVideo/流心播放器](https://github.com/Yebingiscn/SweetVideo) - 为 Harmony OS Next 开发的本地视频软件，基于 流心视频 二次开发 

## Read
- [Harmshelf](https://github.com/shanyan-wcx/Harmshelf) - Audiobookshelf的鸿蒙原生客户端
- [轻阅读](https://github.com/autobcb/read) - 全移动端可用的阅读应用，支持多端同步阅读进度
- ~~[开源阅读](https://github.com/mgz0227/legado-Harmony)~~ - 开源阅读鸿蒙版 （现已闭源）

## Network
- [ClashBox](https://github.com/xiaobaigroup/ClashBox) - 代理软件
- [Moonlight](https://gitee.com/smdsbz/moonlight-ohos) - Moonlight客户端
- [Moonlight V+](https://github.com/AlkaidLab/moonlight-harmony) Moonlight客户端
- [Wake](https://github.com/azhuge233/Wake-HarmonyOS) - 网络唤醒应用
- [AloeSend](https://github.com/Aloereed/localsend-ohos) - 鸿蒙版 LocalSend
- [ZeroTierBox](https://github.com/xiaobaigroup/ZeroTierBox) - 基于 ZeroTier 的虚拟组网工具
- [MeshArc](https://github.com/flypigJ/Tailscale-OHOS) - 鸿蒙版 Tailscale 客户端

## Forum
- [ArkDO](https://github.com/EnjoySR/ArkDO) - 开源LINUX DO社区客户端
- [S1 Orange](https://github.com/wly5556/S1-Orange) - 开源Stage1st论坛客户端

## Tools
- [Termony](https://github.com/TermonyHQ/Termony) - Termux for HarmonyOS Computer
- [Harmonix](https://github.com/harmoninux/Harmonix) - A terminal for running Linux ELF binary on HarmonyOS PC
- [CrossShellNext](https://gitcode.com/OpenHarmonyPCDeveloper/CrossShellNext)  - 适用于OpenHarmony 的SSH连接工具

## Shell
- [HiSH](https://github.com/harmoninux/HiSH) - 在鸿蒙上运行Linux Shell，支持手机、平板、2in1/PC、TV，类似iOS/iPadOS上的iSH

## Development Tools
- [ECHO](https://github.com/liriliri/echo) - 简化对鸿蒙设备操作控制的桌面应用程序，可以看作是 HDC 的图形用户界面
- [HOScrcpy](https://gitcode.com/OpenHarmonyToolkitsPlaza/HOScrcpy) -真机投屏工具
- [Abcde](https://github.com/Yricky/abcde) - openHarmony逆向工具包，初步支持反编译
